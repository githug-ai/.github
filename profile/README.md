### Every agent gets a name. Every commit gets a human.

githug gives each AI coding agent its own identity on GitHub: one-hour, one-repo keys, its own bot, and a chain on every commit back to the person accountable for it. Anyone can check that chain.

- **[hug](https://github.com/githug-ai/hug)**: the CLI. `curl -fsSL https://githug.ai/install | sh`, then `hug init --repo owner/repo`.
- **[verify](https://github.com/githug-ai/verify)**: a free GitHub Action that fails a PR when a commit claims an AI agent nobody can vouch for.
- **[githug.ai](https://githug.ai)**: quickstarts for Claude Code, Codex, GitHub Actions and your own loop, the [roadmap](https://githug.ai/roadmap), and the verify page.

Open beta, free. The CLI and the Action are Apache-2.0. Questions: hello@githug.ai
